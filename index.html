Den ursprungliga frågan

Detta var inte ett särskilt regeringsuppdrag. Vårdanalys initierade studien tillsammans med myndighetens patient- och brukarråd.

Studien sökte svar på två övergripande frågor:

Workshopens registerfråga blir därför: hur kan de patient- och brukarviktiga resultaten följas longitudinellt med länkade register?

Ert uppdrag

Designa den nationella analysen

Skapa ett registerbaserat uppföljningssystem för personer som kommer i kontakt med missbruks- och beroendevården.

1. PopulationVilka ska ingå och hur identifieras de?
2. StartpunktNär börjar uppföljningen?
3. UtfallVilka 3–5 patientviktiga resultat mäter ni?
4. DataVilka register måste länkas?
5. JämförelseFöre/efter, mellan grupper eller båda?
6. BegränsningVilka viktiga resultat saknas ändå?

3-minutersredovisning

Population → Startpunkt → Utfall → Data → Jämförelse → Begränsning

Ledtrådar

Fastnat?

1. Populationen
Diagnos, vårdkontakt, läkemedel eller socialtjänstinsats fångar olika grupper. Vilka missar ni?
2. Tidslinjen
Rita t−3, t−2, t−1, kontakt vid t, t+1, t+2, t+3.
3. Resultat eller effekt?
Att ett utfall förbättras efter vårdkontakt betyder inte att vården orsakade förbättringen.

Rapport 2023:5

Regeringsuppdrag

Vad regeringen bad myndigheten göra

Regeringsbeslut I:9 den 17 juni 2021, dnr S2021/05131. Vårdanalys fick i uppdrag att sammanställa och analysera insatserna och beskriva utvecklingen inom kvinnors hälsa och förlossningsvården 2015–2022.

Fördjupningsstudien I tid och otid formulerade bland annat frågor om:

  • hur belastningen varierar över året och veckan,
  • bemanningsläget vid olika kliniker,
  • anställningsformer, erfarenhet och sysselsättningsgrad,
  • hur arbetstiden fördelas och hur mycket som ligger på obekväm tid,
  • produktiviteten vid förlossningsklinikerna.

Regleringsbrev 2022 redovisar uppdraget med dnr S2021/05131.

Ert uppdrag

Gör regeringsfrågan registerbaserad

Välj minst två av de ursprungliga frågorna och bygg ett nationellt analysupplägg som skulle kunna besvara dem med registerdata och vid behov kompletterande administrativa data.

1. FrågaVilka två frågor väljer ni?
2. AnalysenhetFödsel, klinik, dag, arbetspass eller månad?
3. MåttHur mäter ni belastning, bemanning eller produktivitet?
4. DataVilka register och personalsystem behövs?
5. JämförelseHur gör ni kliniker och tidpunkter jämförbara?
6. DatagapVilken del går inte att besvara nationellt?

3-minutersredovisning

Valda frågor → Analysenhet → Mått → Data → Jämförelse → Datagap

Ledtrådar

Fastnat?

1. Sortera efter datakälla
Patientregister kan beskriva inflöde men inte exakt hur många barnmorskor som var i tjänst. Vad kräver schema- eller lönedata?
2. Belastning
Använd klinik och tidpunkt för varje förlossning. Definiera vad som är ovanligt hög belastning för just den kliniken.
3. Produktivitet
Produktivitet kräver både resursinsats och produktion, exempelvis arbetade timmar per förlossning.
4. Ett steg längre
När ni har ett belastnings- eller bemanningsmått: kan det länkas till patientutfall?

Rapport 2019:6

Egeninitierad studie

Den ursprungliga frågan

Detta var inte heller ett särskilt regeringsuppdrag. Rapporten anger att Vårdanalys initierade studien.

Studien frågade:

  • vad forskningen säger om hinder och möjligheter i övergången,
  • vilka erfarenheter unga, närstående och vårdpersonal har,
  • vilka åtgärder som kan förbättra övergången.

Rapporten pekade dessutom ut ett konkret nationellt datagap: det saknades kvantitativa data om hur många unga som går igenom en övergång, var och när den sker och hur den skiljer sig mellan delar av landet.

Workshopens registeruppgift är därför att bygga just den uppföljningen.

Ert uppdrag

Kan vi hitta dem som faller mellan stolarna?

Bygg en nationell registerbaserad uppföljning som visar vilka unga som går från barn- till vuxensjukvård, när och var övergången sker och vad som händer med kontinuitet och utfall.

1. PopulationVilka unga har ett långvarigt vårdbehov?
2. ÖvergångHur identifierar ni själva övergångstidpunkten?
3. KontinuitetHur mäts glapp, utebliven uppföljning eller läkemedelsavbrott?
4. UtfallAkutvård, slutenvård eller diagnosspecifika komplikationer?
5. JämförelseFöre/efter, regioner, diagnoser eller kohorter?
6. TolkningHur skiljer ni övergången från vanligt åldrande?

3-minutersredovisning

Population → Övergång → Kontinuitet → Utfall → Data → Begränsning

Ledtrådar

Fastnat?

1. Välj en grupp med kontinuerligt vårdbehov
Ett vårdglapp är lättare att tolka om regelbunden uppföljning faktiskt förväntas.
2. 18-årsdagen är inte nödvändigtvis övergången
Kan ni observera sista barnspecialistbesöket och första relevanta vuxenspecialistbesöket?
3. Gör kontinuitet mätbar
Tid till första vuxenvårdsbesök, längsta glapp, utebliven uppföljning eller kontinuitet i läkemedelsuttag.
4. Event study
Följ samma personer från exempelvis 15 till 23 års ålder och studera utvecklingen kring övergångstidpunkten.
